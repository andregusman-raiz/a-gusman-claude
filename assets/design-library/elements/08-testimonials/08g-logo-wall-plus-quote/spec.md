# 08g — Logo Wall + 1 Quote Destacado

## Quando usar
- Landing principal (above or near hero)
- Quando clientes reconhecíveis (brand recognition)
- Social proof em 1 seção compacta

## Quando NÃO usar
- Clientes não-reconhecíveis (logos sem peso)
- Sem autorização de uso dos logos
- Quando quote isolado não representa todos

## Props principais
- `LOGOS` array (labels textuais — em produção: SVGs)
- Quote único + atribuição
- Variante centralizada

## Dependências
- lucide-react (Quote)
- Tailwind grayscale effect

## Variações
- Logos em SVG real (melhor qualidade)
- Com animação de entrada no scroll
- Quote via carousel embaixo

## Anti-patterns
- Logos sem permissão do cliente
- Todos logos do mesmo setor (parece especializado demais)
- Grayscale hover que não retorna (má feedback)
