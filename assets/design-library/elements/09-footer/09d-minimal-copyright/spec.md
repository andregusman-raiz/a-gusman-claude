# 09d — Minimal Copyright Footer

## Quando usar
- Landing enxuta, 1 página
- MVP, beta, projeto interno
- Quando footer longo distrai do CTA principal

## Quando NÃO usar
- Site com SEO importante no footer
- Produto estabelecido com muitas páginas
- Regulamentado (LGPD exige links mais visíveis)

## Props principais
- `brand`, `links` (3 default)
- Ultra-compacto, 1 linha em desktop

## Dependências
- Só Tailwind

## Variações
- Com "Feito por X em Y" (produtoria)
- Com versão (v1.2.3) — git/build info
- Sem logo, só copyright textual

## Anti-patterns
- Adicionar 10 links até virar `09a` (perde propósito)
- Copyright com ano hardcoded (atualizar anualmente manual)
- Footer minimal em site que precisa de sitemap
