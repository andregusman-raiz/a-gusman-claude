# 05a — Full-Bleed Gradient CTA

## Quando usar
- Final de landing page — momento de conversão
- Separador visual entre seções
- Quando já houve "educação" acima e falta o empurrão
- Brand colorida permite gradient forte

## Quando NÃO usar
- Brand sóbria (gradient parece brega)
- Muitos CTAs já visíveis acima
- Páginas minimalistas

## Props principais
- `title` / `subtitle` / `ctaLabel` / `onCtaClick`

## Dependências
- `lucide-react` (ArrowRight)

## Variações (responsive, dark)
- Gradient funciona em light/dark
- Mobile: texto menor mas CTA ainda gigante
- Hover: scale + leve mudança de cor

## Anti-patterns
- 2 CTAs → só 1 gigante faz sentido aqui
- Subtitle > 2 linhas
- Gradient com cores berrantes demais
- CTA com cor do gradient (sem contraste)
